# 🧬 Mixture of Scars (MoS) & SCache Interactive Demo

Interactive demonstration of:
1. **SCache DynamicCache $O(1)$:** Constant memory KV cache replacement using Widrow-Hoff Delta Rule.
2. **Mixture of Scars (MoS):** Universal Shared Bases + Rank-64 Micro-Experts compressing 70B/72B MLPs by $8.8\times$.
3. **Needle In A Haystack (NIAH V2.0):** 100% long-context accuracy up to 64k tokens with $97.6\times$ less memory.
